# 📊 Call Center Performance Dashboard

## Overview

This project analyzes daily call center performance across different agents. The dashboard provides an overview of call volume, customer satisfaction, average handle time and Service Level Agreement (SLA) performance.

## 🔗 Dashboard

👉 [View the Google Sheets Dashboard](https://docs.google.com/spreadsheets/d/1Mc7Y1PrcA95GmMaLz7-sJAjXRqYQLbVej79fzmNOKbY/edit?gid=60714967#gid=60714967)

## 📈 Key Metrics

- Calls Offered
- Calls Answered
- Calls Abandoned
- Handle Time
- CSAT
- SLA %
- Agent Performance


## 🛠️ Tools Used

- Google Sheets
- Data Analysis
- Data Visualization
- KPI Reporting

## 🎯 Objective

The objective of this dashboard is to monitor call center performance and identify trends, operational issues, and opportunities for improvement.

## 📅 Data Granularity

The data is aggregated at the **daily agent level**, allowing performance to be analyzed by date and agent.

## 👤 Role

**Data Analyst / Dashboard Developer**

Responsible for data preparation, analysis, KPI development, dashboard creation, and visualization.
